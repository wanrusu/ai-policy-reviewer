# AI Policy Project Reviewer

A small Streamlit prototype for government think-tank project managers.

## What it demonstrates

- Project Copilot
- Decision Log
- Risk Radar
- Evidence Gap detection
- AI Red Team
- Executive Question simulation

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Enter an OpenAI API key in the sidebar.

## Demo principle

AI structures information, challenges assumptions, and surfaces risks.
The PM retains final judgment.
